# Claude Code бесплатно на своём сервере

[English version](README.en.md)

Проект не связан с Anthropic; Claude Code ставится официальным пакетом.

Помощник для кода и текстов, который работает в терминале вашего сервера. Внутри - Claude Code (оболочка от Anthropic), а вместо платных моделей - бесплатные лимиты нескольких провайдеров. Если у одного кончился лимит или он завис, агент сам переходит к следующему.

## Что это и чего не обещаем

- **Claude Code - да, бесплатно. Модели Claude - нет.** У Anthropic нет бесплатного доступа к API, и у бесплатных провайдеров моделей Claude нет. Работать будут открытые модели: Kimi, DeepSeek, GLM, Nemotron, Qwen, gpt-oss, Gemini Flash и подобные. Они слабее Claude, особенно на больших задачах.
- **Минус: ваши запросы уходят провайдерам.** Всё, что агент читает и пишет (код, тексты, куски файлов), отправляется на серверы выбранных провайдеров. Пароли, ключи доступа, персональные данные и чужие документы агенту не давайте. На некоторых бесплатных тарифах запросы могут использоваться для обучения моделей.
- **Лимиты маленькие и меняются.** К вечеру лучшие модели могут закончиться, тогда агент работает на тех, что остались, или просит подождать. Чем больше провайдеров подключено, тем реже пауза.
- **Одна учётка на провайдера.** Не заводите несколько учёток ради лимитов и не давайте свой ключ другим: это нарушает правила провайдеров и ведёт к блокировке.

## Что нужно

- Сервер (VPS) с Ubuntu 24.04, от 1 ГБ памяти, доступ от имени root или через sudo.
- Почта, а для некоторых провайдеров ещё телефон. Банковская карта не нужна ни одному провайдеру из списка.

Полезные ссылки:

## Установка

Откройте терминал сервера (веб-консоль хостинга или как вы обычно на него заходите) и вставьте одну команду:

```
curl -fsSL https://ty-biznesmen.ru/apps/claude-code-free/install.sh | sudo bash
```

Скрипт читаемый (его можно сначала скачать и посмотреть). Версии всего, что он ставит, зафиксированы. Контрольные суммы сверяются у Node.js и у пакета с этим проектом; Claude Code ставится официальным пакетом из npm нужной версии (проверка целостности npm). Повторный запуск безопасен: он обновит то, что нужно, и не тронет ваши ключи.

Что установка делает:

1. Ставит Node.js 22 в свою папку `/opt/free-agent` (на систему глобально ничего не навешивает) и Claude Code официальным пакетом Anthropic.
2. Создаёт отдельную служебную учётку `freeagent` без входа и обычную учётку `aiagent` без пароля и без прав администратора - под ней агент выполняет команды. Какая бы учётка ни набрала `agent`, Claude Code всегда работает под `aiagent` и не видит ваших переменных окружения.
3. Запускает маршрутизатор как службу systemd. Он слушает только `127.0.0.1`, то есть снаружи недоступен.
4. Включает файрвол ufw: всё входящее закрыто, кроме SSH (порт определяется сам, в том числе нестандартный). Если на сервере уже работают другие службы (сайт, VPN, почта) или порт SSH определить не удалось, файрвол не включается молча: установщик назовёт порты и скажет, что сделать. Ничего наружу не открывается.
5. Настраивает Claude Code на этот маршрутизатор. Вход в подписку Anthropic не нужен, телеметрия выключена.

## Ключи провайдеров (мастер)

```
sudo agent-setup
```

Мастер идёт по провайдерам по очереди: «Шаг 1 из 6: ...». На каждом шаге он показывает:

1. ссылку на регистрацию и что для неё нужно (только почта или ещё телефон);
2. ссылку на страницу, где создаётся ключ;
3. предупреждение про лимиты и про то, что бесплатный тариф может учиться на запросах.

Вы вставляете ключ и нажимаете Enter. Пока вставляете, ключ виден на экране, как обычная команда (так ввод работает и в веб-консоли хостинга в браузере); сразу после Enter строка с ключом стирается и вместо неё остаётся маска вида sk-or-v1-abc…wxyz. Мастер пишет «Ключ получен (N символов), проверяю...» и проверяет ключ тестовым запросом. Если мастер почему-то не принимает ввод, ключ можно передать одной строкой: echo 'ВАШ_КЛЮЧ' | sudo agent-setup add openrouter (вместо openrouter - имя провайдера). Любого провайдера можно пропустить клавишей Enter и вернуться позже:

```
sudo agent-setup add groq       # добавить или заменить ключ одного провайдера
sudo agent-setup list           # у кого ключ есть
sudo agent-setup remove groq    # удалить ключ
```

Провайдеры: NVIDIA build.nvidia.com, OpenRouter, Cerebras, Groq, Mistral, Google AI Studio. Начните с NVIDIA и OpenRouter - они сильнее всего для кода. Google AI Studio из России может не работать. GitHub Models в список не входит: сервис закрыт.

Ключи хранятся в `/etc/free-agent/keys.json` (права 600, читает только служебная учётка). Это обычный файл: кто получил доступ администратора к серверу, тот может его прочитать, поэтому следите за доступом к серверу.

## Как пользоваться

```
agent
```

Откроется Claude Code в папке `/home/aiagent/work` под учёткой `aiagent`. Пишите задачи обычным языком. Из-под обычной учётки команда сама попросит sudo (нужны права администратора).

Как работает переключение:

- провайдер ответил 429 (лимит) - пауза для этой модели (для всего провайдера - если 429 повторяется) и следующий;
- ошибка 5xx или сеть - следующий;
- нет первого слова ответа 30 секунд - следующий (время меняется: `first_token_timeout_s` в `/etc/free-agent/config.json`);
- обрыв ответа посреди текста - Claude Code повторит запрос сам. Переключиться незаметно в этот момент нельзя: часть ответа уже получена.

## Что не работает

- **WebSearch (поиск в интернете из Claude Code) не работает.** Это серверная функция Anthropic, у бесплатных провайдеров её нет. Страницу агент прочитает, только если вы дадите ссылку, а он скачает её командой.
- Картинки (в том числе скриншоты из результатов инструментов) понимают только модели, которые это умеют (Gemini, Gemma); остальные получают пометку «изображение пропущено». Для картинки из результата инструмента модель с vision получает её отдельным сообщением сразу после результата.
- На OpenRouter используются только бесплатные модели (суффикс :free или нулевая цена); платные агент не трогает, даже если они есть в списке.
- Лимиты и список бесплатных моделей у провайдеров меняются без предупреждения, иногда за неделю. Всё, что написано про лимиты, - ориентир, а не обещание.
- Модели слабее Claude: на больших многошаговых задачах агент чаще ошибается и зацикливается. Давайте задачи небольшими кусками.

## Если не работает

- `agent` пишет «Не введено ни одного ключа» - запустите `sudo agent-setup`.
- `agent` пишет, что маршрутизатор не отвечает - `systemctl status free-agent`, журнал: `journalctl -u free-agent -n 50`.
- Ответ «Все бесплатные провайдеры сейчас недоступны» - у всех кончился лимит или они на паузе. Подождите (минуты или до следующих суток), добавьте ещё провайдера (`sudo agent-setup add имя`), посмотрите `agent-stats`.
- Часто видно «429» - это лимит провайдера, агент переключается сам.
- Мастер говорит «не принял ключ» - ключ скопирован не целиком или аккаунт не подтверждён (телефон, регион). Создайте ключ заново.
- Ничего не помогает - удалите (`sudo agent-uninstall`) и поставьте заново; ключи придётся ввести снова.

## Статистика

```
sudo agent-stats        # за сутки
sudo agent-stats 6      # за 6 часов
```

Показывает по каждому провайдеру: сколько попыток, сколько удачных, сколько раз был лимит (429), сбой (5xx), долгое молчание, и среднее время до первого слова. Кому нужен дашборд - используйте исходный проект FreeLLMAPI (https://github.com/tashfeenahmed/freellmapi): в нём есть веб-панель с графиками. Здесь её нет намеренно: меньше кода и меньше открытых портов.

## Модели

Список моделей лежит в `/opt/free-agent/app/catalog/models.json`, порядок в нём - приоритет (сильные для кода сверху). Имена моделей у провайдеров меняются. Мастер сверяет список со списком моделей, доступных именно по вашему ключу, и лишнее пропускает.

## Удаление

```
sudo agent-uninstall
```

Удалит службу, программы, ключи и обе учётки (папка `/home/aiagent` тоже). Файрвол останется включённым, это безопасно; выключить: `sudo ufw disable`.

## Для проверяющих код

Устройство:

- `router/` - маршрутизатор (Node 22, без внешних зависимостей): `server.mjs` (выбор провайдера, паузы, статистика), `upstream.mjs` (ожидание первого токена), `convert.mjs` (перевод Anthropic Messages и OpenAI);
- `cli/setup.mjs` - мастер ключей, `cli/stats.mjs` - статистика;
- `catalog/models.json` - свой каталог провайдеров и моделей, обращений к чужим серверам за каталогом нет;
- `bin/run-claude` - запуск Claude Code под `aiagent`; `install.sh`, `uninstall.sh`;
- `tests/` - тесты: `node --test tests/router.test.mjs` (с моком провайдеров), `bash tests/container-test.sh` (установка в чистой Ubuntu 24.04 в Docker).

Наружу маршрутизатор ходит только к провайдерам, у которых введён ключ. Никакой телеметрии, проверок обновлений и обращений к серверам проекта нет.
